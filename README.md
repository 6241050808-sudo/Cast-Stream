# CarStream Auto (Upgraded Edition)

พัฒนาต่อยอดจาก `thekirankumar/carstream-android-auto` โดยปรับปรุงอินเทอร์เฟซให้แสดงผล YouTube และวิดีโอแบบเต็มหน้าจอสมดุลทั้งบนมือถือและหน้าจอรถยนต์ (Android Auto) พร้อมแก้ไขข้อจำกัดเดิมครบถ้วน

## ฟีเจอร์และการปรับปรุงหลัก
- **โหมดเต็มจออัจฉริยะ (Immersive Fullscreen สำหรับจอมือถือ & จอรถยนต์):** มีปุ่ม **"เต็มจอ / เต็มจอรถ"** ที่มุมขวาบนและในแถบควบคุมด้านล่าง เมื่อกดแล้วจะซ่อนแถบเมนูและ System Bars ทั้งหมดเพื่อให้แสดง YouTube เต็มพื้นที่ 100%
- **ปรับสัดส่วนภาพสมดุล (Aspect Ratio & Zoom Calibrator):** รองรับ `16:9 มาตรฐาน`, `21:9 จอกว้างในรถ (Ultrawide)`, `Full Stretch` และ `Cinema Zoom` โดยไม่ตัดขอบคอนเทนเนอร์ของหน้าเว็บ
- **แป้นพิมพ์ในรถ (In-Car Rotary & Touch Keyboard):** แก้ปัญหาปุ่ม `@` หายและแก้บั๊กกด Enter แล้วช่องกรอกถูกล้างค่า พร้อมโหมดส่งข้อความเข้าช่องกรอกเว็บโดยตรง
- **ชดเชยความหน่วงเสียง (Bluetooth / Wireless AA Audio Sync):** ปรับจูนความหน่วงเสียง `-400ms` ถึง `+400ms`
- **เล่นไฟล์วิดีโอในเครื่อง (MP4/MKV):** ใช้ Android Photo Picker มาตรฐานใหม่ ไม่ติดบล็อกสิทธิ์การเข้าถึงไฟล์บน Android 14/15+

## วิธีดาวน์โหลดและสร้างไฟล์ APK บน GitHub
1. **ผ่านเมนู AI Studio:** กดที่เมนูตั้งค่า (Settings / Export) มุมขวาบนเพื่อเลือก **Push to GitHub** หรือ **Generate APK** ได้ทันที
2. **ผ่าน GitHub Actions อัตโนมัติ:** เมื่อ Push โค้ดขึ้น GitHub แล้ว ไฟล์เวิร์กโฟลว์ `.github/workflows/build-apk.yml` จะทำการคอมไพล์และสร้างไฟล์ `CarStream-Auto-APK` ให้ดาวน์โหลดได้ทันทีในแท็บ **Actions** ของ GitHub
